# AGENTS.md

This repository's project instructions for AI coding agents live in **`CLAUDE.md`** at
the repo root. That file is the canonical source — read it before making changes here.

It covers setup/commands, monorepo architecture, backend/frontend patterns, permissions
and authorization layers, translations, deployment targets, and more.

Additionally, `.cursor/rules/*.mdc` has deeper, example-heavy versions of parts of
`CLAUDE.md` (GraphQL mutation walkthroughs, test patterns, styling/icon/i18n
conventions, CI preflight checks) — check the relevant file there when you need a
copy-pasteable example rather than the summary in `CLAUDE.md`.

If `CLAUDE.md` and this file ever disagree, `CLAUDE.md` wins — update this pointer
file instead of duplicating content into it.
